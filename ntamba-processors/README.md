# Ntamba Processors WordPress Theme

Original WordPress/WooCommerce theme for Ntamba Processors Limited.

## Dynamic WooCommerce
The theme pulls live WooCommerce product data at runtime. Product cards do not hardcode the 17 catalogue records; SKU, price, image, stock, weight and available GTIN metadata are read from the WooCommerce backend.

## Design
Brand palette:
- Deep Coffee Brown #4A3728
- Agroecology Green #2D5A27
- Warm Honey Gold #D4A017
- Warm Cream #F9F7F2

The visual direction is original to Ntamba Processors and uses the provided Kaffa site only as a high-level presentation reference. No Kaffa code, branding, artwork or content is included.

## Setup
Install WordPress + WooCommerce, upload the `ntamba-processors` directory as a theme, activate it, then configure logo, hero image, social links and contact information in Appearance → Customize.
